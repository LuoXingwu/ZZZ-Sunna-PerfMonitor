========================================================
    绝区零千夏电脑帧数性能监视器  v1.0  安装教程
              （请先读完这一页再开始）
========================================================

【第零步】解压

  如果你现在是在压缩软件（WinRAR/360压缩等）的窗口里看到这些文件，
  请先把整个文件夹【解压】出来再操作——直接在压缩软件里双击运行是
  无法正常工作的。
  （右键压缩包 → 解压到当前文件夹。解压得到的项目文件夹名字形如
  ZZZ-Sunna-PerfMonitor 或 ZZZ-Sunna-PerfMonitor-main，从哪个渠道
  下载的叫法略有不同，不影响使用，进入它继续即可）

  系统要求：Windows 10 或 11（64 位）。不需要安装任何运行环境。


【第一步】启动桌宠（10 秒）

  打开解压出来的文件夹，进入 daemon 文件夹，双击：

      pet_launcher.vbs

  几秒后，桌面上会出现她的小伙伴：人物、数据栏、吉他、画架、
  泡泡酱——平时共 5 个；她说话时旁边还会冒出一个气泡
  （气泡只在说话时出现，平时看不到不是丢了！）。
  它们会实时播报你电脑的运行状态。

  · 拖动任意一个组件 = 整组一起移动（可跨屏幕）
  · 在组件上滚动滚轮 = 整体放大缩小
  · 左键点人物 = 换动作；左键点泡泡酱 = 切换监控的屏幕
    （只有一块屏幕时点了只换个名字，她会口头告诉你，正常现象）
  · 右键任意组件 = 菜单（说话/换动作/复位/置顶/退出）
  · 退出：右键桌宠 → 退出


【第二步】开机自启（可选，30 秒）

  1. 在 daemon 文件夹里右键 pet_launcher.vbs → 创建快捷方式
  2. 按 Win + R 键，输入  shell:startup  回车（打开"启动"文件夹）
  3. 把刚创建的快捷方式剪切/复制进去

  完成。以后开机桌宠自动出现。

  另外首次启动时，桌面会自动生成一个"性能监视桌宠"快捷方式
  （带角色图标，双击它随时可以打开桌宠）。不想要可以删掉，
  不会再自动出现。


【第三步】显示真实游戏帧率：一键安装 RTSS（可选，推荐玩游戏的人做）

  桌宠没有 RTSS 也能正常使用，此时面板第一格显示的是
  显示器的刷新率（比如 60 / 144 / 165）。想让它显示游戏的
  【真实帧率】，安装小工具 RTSS 即可——安装包已经帮你打包好
  （官方原版，未做任何修改），双击就能装：

  1. 进入 daemon 文件夹，双击：

         install_rtss.vbs

  2. 弹出蓝色的"用户账户控制"确认框时，点【是】。

  3. 黑色窗口自动跑完，看到 [OK] RTSS installed and started
     就成功了——桌面上还会自动生成一个"RTSS 帧数工具"快捷方式。

  4. 之后不用你操心：桌宠运行时会自动启动 RTSS（万一系统
     弹确认框，点【是】即可）；退出桌宠时也会尝试一并关闭。

  5. 验证：重启一次电脑（最稳妥），然后启动一个游戏，看桌宠
     面板第一格——显示游戏帧率并随场景变化 = 成功！

  ※ 一键安装如果失败，可以手动装：浏览器打开

         https://www.guru3d.com/download/rtss-rivatuner-statistics-server-download/

     （RTSS 官方站）下载安装包，一路【下一步 / Next】即可，
     效果完全一样。


【第四步】看懂面板上的数字

  FPS 格：
    · 游戏中 → 显示游戏的真实帧率（跳动是正常的）
    · 平时   → 显示显示器的刷新率（固定值，面板会标"日常/REFRESH"）
    · 显示 -- → RTSS 没在运行（装了 RTSS 重启电脑即可）

  GPU 格：
    · NVIDIA 显卡自动可用
    · 其他品牌显卡（AMD/核显）显示 0%，属正常，其余功能不受影响

  CPU / MEM 格：所有电脑通用，无需设置。


【第五步】常见问题

  1. 双击 pet_launcher.vbs 没反应或被拦截？
     → 杀毒软件/Windows Defender 可能对脚本类文件敏感，
       在杀毒软件里把本文件夹加入信任/白名单即可。
       也可以右键 pet.ps1 → "使用 PowerShell 运行"。

  2. 想改台词、改桌宠显示的名字？
     → 用记事本编辑 assets\lines.json（台词）和
        assets\ui.json（界面文字与屏幕昵称），
        保存后右键桌宠退出再重新启动生效。

  3. 玩游戏时感觉掉帧？
     → 先右键桌宠 → 取消置顶试试（置顶窗口可能影响部分
        游戏的全屏模式）。更多排查方法见 README.md 里
        "游戏掉帧了？先分清是谁的锅"一节。

  4. 想放大/缩小？
     → 鼠标悬停在任意组件上滚动滚轮，整组一起缩放。

  5. 一键安装 RTSS 失败？
     → 用第三步末尾的官方网址手动下载安装，效果完全一样。


【第六步】卸载

  1. 右键桌宠 → 退出
  2. 删除整个文件夹即可（本程序不写注册表、不留垃圾）
  3. 如果装过 RTSS：控制面板 → 程序和功能 → 卸载
     RivaTuner Statistics Server
  4. 如果设置过开机自启：删除 shell:startup 里的快捷方式
